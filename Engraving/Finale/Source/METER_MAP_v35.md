# v35 meter-map reference

## Authority and scope

`FlashlightsInTheDark_v35_meter-map.musicxml` is the exported MusicXML
reference for the meter mapping currently saved in
`FlashlightsInTheDark_v35_pages7-8_text.musx`.

Use this file to verify meter structure for all future engraving work. It is
an uncompressed MusicXML export so its measure and time-signature elements can
be inspected directly. It is not, by itself, approval to replace the live
Finale source or to overwrite lyric, layout, or placement-specific work.
