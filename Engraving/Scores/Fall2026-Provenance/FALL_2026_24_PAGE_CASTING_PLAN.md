# Fall 2026 24-page performer-score casting

## Recommendation

Use 23 music pages plus a nonblank native Dorico colophon on page 24.  This is
the first casting that gives every Stage D system-on-system collision a
structural answer without shrinking the 1.5 mm staff or the 11 pt lyric style.
Page 1 retains exactly two systems.  Later pages use one system wherever the
six-staff lyric/direction envelope proved too tall, and two systems only for
pairings that were clean in Stage C/D or are materially lighter after the
semantic cleanup.

The page-1 split is deliberately rebalanced from 1-5 / 6-10 to 1-6 / 7-10.
In the validated Stage E source, the former systems carry 65 versus 97
sounding notes and 46 versus 74 lyric anchors; the revised systems carry 74
versus 88 sounding notes and 53 versus 67 lyric anchors.  Moving the relatively
light m.6 to the first system therefore reduces the second system's load while
leaving the first within a plausible horizontal envelope.  This directly
answers the Stage E finding that the former second system was catastrophically
congested.

The optional generated source is
`FlashlightsInTheDark_Fall2026_Dorico24PageCasted.musicxml`.  It is separate
from, and does not overwrite, the current 15-music-page casting.

## Native Dorico follow-through

Import the optional cast MusicXML into a new Dorico project.  Preserve all 23
music pages, create a nonblank colophon as page 24 with a page-template
override, and then perform the full visual QA.  MusicXML cannot reliably force
the trailing Dorico colophon, so the generated file intentionally contains no
synthetic blank page or page-attached credit workaround.

Do not append the existing `FlashlightsInTheDark_Fall2026_Page16_Colophon.pdf`
unchanged: its PDF metadata identifies it as page 16 and its lower-left folio
visibly reads `16`.  It is a valid content/style reference for the even-numbered
page 24, but it must be recreated or re-exported with folio `24` before the
final merge.
