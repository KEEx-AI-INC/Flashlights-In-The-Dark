# Engraving

`Scores/` contains the authoritative MusicXML/PDF delivery material. For the
Fall 2026 SingerScore update, begin with
`Scores/FlashlightsInTheDark_v26_NewerScoreWithFewerParts.musicxml`.
`Finale/Source/` is the active authored-score handoff folder;
`Finale/Source/Source_Archive/` retains the historical editable Finale
lineage, and `Finale/Backups/` retains dated backup files. `Score-Study/`
contains analytical and reference material derived from those scores.

Runtime copies inside `Software/` are generated delivery assets; revise the score here first, then use `Operations/Scripts/` to regenerate show-control and runtime outputs.
