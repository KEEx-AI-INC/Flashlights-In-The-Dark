# Show-Control

This domain contains dated generated recipe releases, canonical trigger maps, and show profiles. Release directory names are provenance identifiers and must remain stable.

Do not hand-edit copied runtime recipes. Update their canonical inputs in `Engraving/` and regenerate through `Operations/Scripts/`.

`Topology/FlashlightsInTheDark_v36_36PhoneTopology.json` records the
topology-independent V36 review design: 30 musical routes plus six normally
dark hot reserves. It is an authoring/review input only and is not installed in
either runtime application.
